Utilización de Angular

Una vez que Angular se encuentra instalado y el proyecto ha sido generado, la utilización del framework se basa en una serie de comandos y prácticas que permiten crear componentes, configurar rutas, comunicarse con servicios y ejecutar la aplicación durante el desarrollo. Angular está diseñado para trabajar de forma modular, por lo que el uso cotidiano implica crear piezas pequeñas y organizadas que forman una aplicación completa.

Ejecutar el proyecto durante el desarrollo

El primer paso en la utilización de Angular es poner en marcha el servidor de desarrollo. Esto permite visualizar la aplicación y ver los cambios en tiempo real, ya que el framework recompila cada modificación automáticamente. Para iniciar el proyecto basta con situarse dentro de la carpeta del proyecto y ejecutar: 

cd nombre_del_proyecto
ng serve --open

El navegador se abrirá en http://localhost:4200, donde se puede interactuar con la aplicación mientras se desarrolla.

Creación de componentes

Angular trabaja sobre una arquitectura basada en componentes, por lo que uno de los usos más comunes es generar nuevos componentes que representen partes específicas de la interfaz, como menús, formularios, tarjetas o páginas completas. La CLI permite crearlos de manera automática con un solo comando: 

ng generate component nombre_componente

Esto crea los archivos necesarios (HTML, TS, CSS y un archivo de pruebas) dentro de la estructura adecuada del proyecto. Cada componente tiene su propia vista y su propia lógica, lo que facilita mantener el código limpio y organizado.

Creación y uso de servicios

Los servicios son otra parte fundamental de la utilización de Angular. Se emplean para almacenar lógica reutilizable, gestionar datos, comunicarse con APIs externas y compartir información entre componentes. Para crear uno se utiliza: 

ng generate service nombre_servicio

Un servicio puede realizar peticiones a un servidor utilizando HttpClient. Un ejemplo simple sería: 

constructor(private http: HttpClient) {}

getDatos() {
  return this.http.get('https://api.ejemplo.com/datos');
}

Este servicio puede ser utilizado por cualquier componente que lo necesite, manteniendo la lógica separada de la interfaz y facilitando el mantenimiento.

Navegación mediante rutas

Angular permite definir rutas para navegar entre diferentes vistas dentro de la aplicación, evitando recargas de página. La configuración se realiza en el módulo de enrutamiento y permite asignar un componente a cada camino o URL. Una configuración básica podría ser: 

const routes: Routes = [
  { path: '', component: HomeComponent },
  { path: 'productos', component: ProductosComponent },
  { path: 'contacto', component: ContactoComponent }
];

Con estas rutas definidas, se puede navegar mediante enlaces: 

<a routerLink="/productos">Ver productos</a>

Modificación de vistas y estilos

La utilización diaria también implica trabajar sobre las plantillas HTML y los estilos CSS de cada componente. Angular permite vincular datos desde la lógica al HTML mediante interpolación: 

<p>Bienvenido, {{ nombreUsuario }}</p>

Y permite aplicar estilos locales sin afectar al resto de la aplicación, ya que cada componente tiene su propio archivo .css. Esto evita conflictos y hace más sencillo modificar partes concretas de la interfaz.

Gestión del proyecto y compilación final

Una vez finalizado el desarrollo, Angular permite generar una versión optimizada de la aplicación lista para desplegar en un servidor. El comando utilizado para este proceso es: 

ng build --configuration production

Este comando crea una carpeta dist/ con todos los archivos optimizados y listos para ser publicados en cualquier servicio web o infraestructura de hosting.

En resumen, la utilización de Angular se basa en un flujo de trabajo guiado por la CLI, apoyado en componentes, servicios y rutas, lo que permite construir aplicaciones complejas de manera organizada y con herramientas que facilitan tanto el desarrollo como el mantenimiento.
