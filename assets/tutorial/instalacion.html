Instalación de Angular

Antes de comenzar a trabajar con Angular es necesario preparar el entorno adecuado, ya que este framework no funciona directamente en el navegador sin una configuración previa. Angular sí requiere instalación, principalmente porque se apoya en herramientas que permiten crear, compilar y ejecutar proyectos de manera organizada. La pieza fundamental es Angular CLI, la línea de comandos oficial que automatiza la creación de componentes, servicios, rutas y toda la estructura interna del proyecto.

¿Se precisa instalación?

Sí. Para utilizar Angular es indispensable instalar varias herramientas previas que permiten gestionar el proyecto y ejecutar la aplicación. El framework depende de Node.js, de npm y de Angular CLI, que es el sistema que genera la estructura necesaria y facilita todas las tareas del desarrollo.

¿Qué pasos hay que realizar para realizar la instalación?

Primero es necesario instalar Node.js, que incluye el gestor de paquetes npm. Una vez hecho esto, se puede instalar Angular CLI y crear un proyecto nuevo usando los siguientes comandos:

Verificar versiones instaladas:

node -v
npm -v

Instalar Angular CLI de forma global:

npm install -g @angular/cli

Crear un nuevo proyecto Angular:

ng new nombre_del_proyecto

Acceder al proyecto recién creado:

cd nombre_del_proyecto

Iniciar el servidor de desarrollo:

ng serve --open

Con estos pasos básicos ya se obtiene un entorno funcional y listo para comenzar a desarrollar aplicaciones con Angular.

Versiones necesarias

Angular no obliga a usar versiones exactas, pero sí es recomendable trabajar con versiones actuales de Node.js, preferiblemente una versión LTS para asegurar compatibilidad. Angular CLI se actualiza constantemente, y cuando se crea un proyecto nuevo, este incluye automáticamente la versión estable del framework.

Rutas para tener en cuenta

Después de crear el proyecto, Angular genera una estructura organizada en diferentes carpetas. La ruta más relevante es src/app, donde se encuentran los componentes, servicios y módulos principales del proyecto. La carpeta node_modules contiene las dependencias instaladas mediante npm y no debe modificarse manualmente. El archivo angular.json ubicado en la raíz del proyecto controla la configuración global.

Variables de entorno

Aunque Angular no requiere variables de entorno para empezar a funcionar, sí permite definirlas cuando es necesario diferenciar configuraciones para desarrollo, pruebas o producción. Estas variables se gestionan en la carpeta src/environments, donde se encuentran archivos como: 

src/environments/environment.ts
src/environments/environment.prod.ts

¿Necesita base de datos?

Angular no necesita una base de datos para instalarse o ejecutarse, ya que trabaja exclusivamente en el lado del cliente. No gestiona almacenamiento por sí mismo, pero puede conectarse fácilmente a APIs externas y servicios backend que sí utilicen bases de datos. En otras palabras, Angular consume datos, pero no los almacena internamente.
