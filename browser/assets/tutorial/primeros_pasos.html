Primeros pasos con Angular

Una vez instalado Angular y creado el proyecto inicial, los primeros pasos consisten en comprender la estructura básica que genera la CLI, aprender a modificar el componente principal y crear nuevos componentes que permitirán construir la aplicación. Angular funciona mediante una arquitectura basada en componentes, donde cada sección visible de la interfaz se organiza como una pieza independiente con su propio código.

Estructura inicial del proyecto

Tras ejecutar el comando de creación del proyecto, Angular genera una carpeta con una estructura organizada que permite comenzar a trabajar de inmediato. La parte más importante es la carpeta src/app, que contiene el componente principal llamado AppComponent. Este componente actúa como punto de entrada de la aplicación y es donde se comienza a integrar contenido.

Creación del proyecto:

ng new nombre_del_proyecto --routing --style=css

Este comando genera todo lo necesario para empezar: un módulo principal, un sistema de rutas opcional y un conjunto de archivos preparados para su uso inmediato.

Arrancar el servidor de desarrollo

Para visualizar los primeros resultados es necesario iniciar el servidor de desarrollo. Angular recompila en tiempo real, lo que significa que cualquier cambio se refleja en el navegador de manera automática. 

cd nombre_del_proyecto
ng serve --open

El proyecto se abrirá en http://localhost:4200. Desde este punto ya se puede comenzar a editar el componente principal para personalizar la aplicación.

Modificar el componente principal (AppComponent)

El archivo app.component.html contiene la plantilla inicial que muestra Angular al cargar la aplicación. Modificarlo es el primer paso para personalizar el proyecto. Por ejemplo, se puede añadir un mensaje de bienvenida muy simple: 

<h1>Bienvenido a mi primer proyecto con Angular</h1>

Este archivo está directamente vinculado al archivo app.component.ts, donde se encuentra la lógica del componente. En esta etapa inicial no es necesario modificar la lógica, pero es útil saber que es aquí donde se gestionan variables, funciones y comportamiento dinámico.

Crear el primer componente

Uno de los primeros pasos fundamentales es crear componentes adicionales para separar partes de la interfaz. Angular facilita esta tarea mediante un comando específico que genera todos los archivos necesarios manteniendo la estructura recomendada. 

ng generate component saludo

Este comando crea una carpeta con cuatro archivos: HTML, TypeScript, CSS y pruebas. El componente puede contener contenido simple, como un texto de bienvenida: 

<p>¡Hola! Esto es un componente de saludo.</p>

Para mostrar este componente en la página principal, basta con insertarlo dentro de app.component.html: 

<app-saludo></app-saludo>

Comprender cómo Angular muestra la información

Angular utiliza un sistema de interpolación que permite mostrar datos desde la lógica (archivo .ts) hacia la vista (archivo .html). Por ejemplo, si en el archivo app.component.ts se define una variable: 

titulo = 'Mi primer proyecto Angular';

Se puede mostrar en la plantilla con: 

<h2>{{ titulo }}</h2>

Este mecanismo permite actualizar la interfaz automáticamente cuando cambian los datos, lo que hace que Angular sea ideal para aplicaciones dinámicas.

Editar estilos y personalizar componentes

Cada componente tiene su propio archivo CSS, lo que permite modificar su apariencia sin afectar al resto de la aplicación. Esto facilita trabajar con estilos independientes para cada parte de la interfaz. Por ejemplo: 

h2 {
  color: #4f46e5;
  font-size: 24px;
}

Gracias a esta separación es posible crear interfaces complejas sin que los estilos entren en conflicto.

Conclusión de los primeros pasos

En resumen, los primeros pasos con Angular consisten en familiarizarse con la estructura del proyecto, aprender a modificar el componente principal, crear y mostrar nuevos componentes, trabajar con interpolación y comprender cómo se organizan los estilos. Estos fundamentos permiten construir aplicaciones más elaboradas incorporando rutas, servicios y comunicación con APIs, que se verán en etapas posteriores.
